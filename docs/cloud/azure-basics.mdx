# Cloud Infrastructure Fundamentals

## Virtual Machines (VMs)
Virtual Machines are software-based emulations of physical computers. They run an operating system and applications just like a physical machine but are decoupled from the underlying hardware, allowing for flexibility, scalability, and resource isolation.

## Networking
Cloud networking defines how resources communicate within a cloud environment and with the outside world. Key components include:
- **VPCs (Virtual Private Clouds):** Isolated virtual networks.
- **Subnets:** Segments of a VPC network.
- **Load Balancers:** Distribute incoming traffic across multiple targets.
- **Firewalls/Security Groups:** Control inbound and outbound traffic access.

## Storage
Cloud storage provides scalable, durable, and secure data management. Common types include:
- **Object Storage:** Stores data as objects (e.g., AWS S3, Google Cloud Storage) for unstructured data.
- **Block Storage:** Acts like a hard drive attached to a VM (e.g., EBS, Persistent Disk).
- **File Storage:** Shared file systems accessible by multiple instances (e.g., NFS, SMB).

## Identity Management
Identity and Access Management (IAM) is the framework of policies and technologies that ensure the right people and machines have the appropriate access to technology resources.
- **Authentication:** Verifying who a user or service is.
- **Authorization:** Determining what an authenticated user or service is allowed to do.
- **Principle of Least Privilege:** Granting only the minimum permissions necessary to perform a task.
